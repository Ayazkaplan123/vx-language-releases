# VX-Lang Releases

Public download repository for official, prebuilt VX-Lang runtime packages. The source repository remains private; this repository contains release assets and their checksums, not the source tree or its Git history.

## Download VX-Lang 0.1.0

Go to the [v0.1.0 release page](https://github.com/Ayazkaplan123/vx-language-releases/releases/tag/v0.1.0) and download the archive for your platform. Verify the SHA-256 checksums against `SHA256SUMS` before installing.

Available targets: Windows x86_64, Linux x86_64, macOS Apple Silicon (arm64), and macOS Intel (x86_64).

The v0.1.0 binaries were built from the private source repository's `v0.1.0` tag at commit `8ff12bc42c474009e0c5789af58decb0a43a5013`. The four platform build and packaging jobs passed before publication. macOS binaries are not signed or notarized.

Each archive contains the runtime, MIT license, and installation instructions. Python is not required to run the native runtime.
